## 바뀐 점 (50차 → 51차)

1. **메인 지도에서 건물을 두 번 누르면 이름을 바꿀 수 있습니다.** (전에는 첫 번째 클릭에 화면이 다시 그려져서 두 번 누르기가 인식되지 않았습니다.)
2. **건물 위에 빨간 ✕ 삭제 버튼이 나옵니다.** 마우스를 올리거나 건물을 누르면 보이고, 누르면 바로 삭제됩니다. 7초 안에 "되돌리기"로 복구할 수 있습니다. 건물은 언제든 끌어서 옮길 수 있습니다.
3. **건물 짓기 화면에서 그림을 누르면 바로 지도에 건물이 놓입니다.** 검색·종류 선택으로 그림 목록이 바뀌고, "더 보기"로 1,000종을 모두 볼 수 있습니다.
4. **건물 짓기 화면에서 마우스로 바로 고칠 수 있습니다.** 선택한 건물에 빨간 ✕(삭제)와 파란 ⤡ 손잡이(끌어서 크기 조절)가 붙습니다. 건물을 끌면 이동합니다.
5. **💾 저장 후 나가기 버튼**을 건물 짓기 화면 위쪽에 넣었습니다.
6. **"수정 38" 표시를 모두 지웠습니다.** (위쪽 노란 띠, 지도 도구 줄, 게임 상위메뉴)
7. **영어 문제를 학기마다 150개 이상으로 늘렸습니다.** 초1-2 ~ 고3-2 23개 학기에 단어·문장·독해 지문을 더하고, 새 문제 유형 "철자 바르게 고르기"를 넣었습니다. 대결에 실제로 나오는 문제 수는 학기마다 151~157개입니다. (초1-1은 원래 202개)
8. 지도 도구 버튼을 처음 누를 때 음악 버튼 글자가 바뀌면서 줄이 밀려 다른 버튼이 눌리던 문제를 고쳤습니다.
9. 51차 업데이트 안내 카드가 나옵니다.
