## 바뀐 점 (125차 → 126차)

125차의 부드러운 입체 느낌은 그대로 두고, 연해 보이던 것을 진하게 바꿨습니다.

1. **색**: 크림빛을 빼고 채도를 높여서 옷·탈인형·동물 색이 선명합니다. 밝은 쪽은 덜 하얗게, 어두운 쪽은 더 진하게 해서 명암 대비가 커졌습니다.
2. **테두리**: 더 굵고(0.6 → 0.9) 거의 불투명한 진한 갈색으로 또렷하게 했습니다. 팔·다리 테두리도 진해졌습니다.
3. **그림자**: 발밑 그림자를 조금 더 진하게 했습니다. 빛 반사는 살짝 줄였습니다.
4. 원래 방문객도 같이 진해집니다. 흰 탈인형은 흰색 그대로입니다.
5. 126차 업데이트 안내 카드.
