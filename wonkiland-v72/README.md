## 바뀐 점 (71차 → 72차)

1. **한 번 누르면 바로 구경하기 화면이 열리고** 맨 위에 진행 상태가 보입니다.
2. **지난번 자료를 먼저 보여 주고**, 최신 자료가 오면 바꿉니다(관리자 기기에만 보관).
3. 처음 열 때는 **회원 명단(빠름)을 먼저** 보여 주고, 공원·게임 기록은 도착하는 대로 채웁니다.
4. 늦으면 5초 뒤 한 번 더 요청하고, 최대 60초까지 기다립니다. 여러 번 눌러도 요청이 겹치지 않습니다.
