## 바뀐 점 (70차 → 71차)

1. 최근 방문한 회원도 **5초 안에 답이 없으면 한 번 더 요청**하고 먼저 온 답을 씁니다. (시험: 첫 요청이 25초 걸리는 서버에서 5초 만에 표시)
2. 기다리는 시간을 20초 → 45초로 늘렸습니다.
3. 관리자 메뉴를 열면 **지난번에 받은 기록을 먼저 보여 주고**, 새 기록이 오면 바꿉니다. 맨 위에 "✓ 오후 2:33 기준 · 5초 걸림"처럼 표시합니다.
