## 원인

- 서버를 확인해 보니 지금은 **현재회원 6명**(엄재민·정윤서·김홍서·구서준·전우현·고다윤), **휴회 3명**(허윤·정태윤·정채윤)이고 **정윤서는 1명**입니다.
- 다시 생기던 "또 하나의 정윤서"(번호 …8iyrq)는 **11월 3일에 예전 버전이 삭제 표시(deletedAt)를 해 둔 사본**이었습니다.
- 상상코칭 회원 목록은 이 표시를 무시하고 계속 보여 줬고, 동기화할 때 이 사본을 **서버에 다시 올렸습니다.** 김..·정도윤도 같은 경우였습니다.
- 시험에서 85차는 이 사본을 서버에 다시 올렸고(`admin_save`), 86차는 서버에서 지웠습니다(`admin_member_delete`).
