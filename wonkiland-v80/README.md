## 바뀐 점 (79차 → 80차)

### 주인장 공원 기기끼리 공유

- 주인장 기기(일반회원 로그인 안 함)에서 원기랜드를 열면 **서버의 주인장 공원을 불러와서** 그대로 보여 줍니다.
- 건물을 짓거나 고치면 **자동으로 서버에 저장**됩니다(관리자 로그인 상태일 때, 건물 짓기 창을 닫은 뒤 몇 초 안에). 그래서 컴퓨터·휴대폰·방문자가 모두 같은 공원을 봅니다.
- 지도 도구의 **☁ 주인장 공원** 버튼에 상태가 보입니다.
  - "☁ 주인장 공원 저장됨"
  - "☁ 저장 안 됨 · 눌러서 저장" — 로그인이 필요할 때. 누르면 로그인하고 저장합니다.
- 다른 기기에서 저장한 것은 그 기기를 열 때, 화면으로 돌아올 때, 2분마다 불러옵니다.
- **이 기기와 서버가 서로 다르면** 양쪽의 건물 이름을 보여 주고 물어봅니다.
  - 확인 = 서버 것으로 바꾸기
  - 취소 = 이 기기 것을 서버에 저장
  - 예: 회전찻잔이 남아 있던 컴퓨터를 열면 "서버: 건물 0개 / 이 기기: 회전찻잔"이 나오고, 확인을 누르면 컴퓨터에서도 사라집니다.

### 관리자 로그인 6시간

- Google 로그인 표는 1시간짜리라 그대로는 늘릴 수 없습니다. 그래서 Google 로그인을 한 번 확인하면, 서버가 **6시간짜리 원기랜드 관리자 표**를 따로 발급합니다.
- 주인장 기기에 기억해 두어 **창을 닫았다 열어도 6시간 동안** 다시 로그인하지 않아도 됩니다.
- 6시간이 지나거나 서버가 표를 잊으면 다음 관리자 작업 때 다시 로그인 창이 나옵니다.

80차 업데이트 안내 카드는 주인장 기기에서만 보입니다.
