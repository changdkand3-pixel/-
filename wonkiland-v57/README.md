## Neocities에 올리는 방법

1. `wonkiland_v57.html`을 받습니다. 글자가 가득한 화면이 나오면 **마우스 오른쪽 버튼 → 다른 이름으로 저장**.
2. Neocities에서 원기랜드를 올리던 폴더(`작업장` 등)를 열고 HTML 파일을 올립니다.
3. 그림 파일(`.webp` 등)은 **폴더 없이 HTML과 같은 폴더**에 있어야 합니다. 56차 때 파일을 모두 선택해서 올리셨다면 이미 그렇게 되어 있습니다.
4. 예전 주소(`웰컴투 원기랜드`)를 쓰려면 HTML 파일 이름만 바꿔서 올리면 됩니다.

## 바뀐 점 (56차 → 57차)

- Neocities 무료 계정은 **mp3 파일을 올릴 수 없고**, **폴더째 올리기도 안 됩니다.** 그래서:
  - 음악은 예전처럼 **HTML 안에 다시 넣었습니다.** (HTML 약 12MB, 80MB까지 여유 충분)
  - 그림은 `images` 폴더 없이 **HTML 옆에 바로 두는 방식**으로 바꿨습니다. 56차 때 올린 그림 312개를 그대로 씁니다.
- 기능은 55·56차와 똑같습니다.
- 57차 업데이트 안내 카드.

이미 올라간 mp3 파일이 있다면 지워도 됩니다(오류로 올라가지 않았을 수도 있습니다).
