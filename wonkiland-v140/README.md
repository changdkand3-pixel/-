## 바뀐 점 (139차 → 140차)

1. **영어 독해 지문 새로 만들기**
   - 예전에 만든 지문은 2~5문장짜리 같은 틀이었고 "○○가 무엇을 하는 요일은?" 같은 어색한 질문이 있었습니다.
   - 이제 6가지 이야기에서 지문을 만듭니다: 자기소개 · 하루 일과 · 주말 나들이 · 생일 파티 초대 편지 · 현장 체험 학습 안내문 · 잃어버린 물건 찾기.
   - 길이는 학년에 맞춥니다: 초1~2 약 5문장, 초3~4 6~8문장, 초5~6 8~11문장, 중·고 9~12문장.
   - 질문도 다양해졌습니다: 내용 찾기, 시각·날짜, 순서(가장 먼저 한 일), 이유(왜 ~했나요), 글의 목적·주제, 글의 내용과 맞는 것 고르기.
   - 지문 하나에서 질문은 6개까지만 내고, 학기마다 지문이 약 50개입니다.
