# 원기랜드 82차 — 광고 없는 짧은 주소 `hinsrolin.neocities.org/w`

## 왜 bit.ly 화면이 나오나요?

bit.ly 무료 줄임 주소는 누르면 **bit.ly가 광고와 "목적지 미리보기" 화면을 중간에 끼워 넣습니다.** 원기랜드 쪽에서는 끌 수 없습니다. 그래서 주인장 사이트 안에 **광고 없는 짧은 주소**를 만들었습니다.

## 해야 할 일 3가지

### 1. 짧은 주소 파일 `w.html` 올리기 (한 번만)

**[w.html 받기](https://github.com/changdkand3-pixel/-/raw/claude/adoring-darwin-mewhr1/wonkiland-v82/w.html)** → Neocities 대시보드의 **맨 위 폴더(Home, 다른 폴더 안이 아님)** 에 `w.html` 이름 그대로 올립니다.

올린 뒤 **https://hinsrolin.neocities.org/w** 를 열면 바로 원기랜드로 갑니다.

### 2. 인스타·카톡에 올린 링크 바꾸기

bit.ly 링크 대신 아래 주소를 쓰세요. 뒤에 `?src=이름`을 붙이면 📊 방문 경로에서 따로 셉니다.

| 올리는 곳 | 주소 |
|---|---|
| 인스타 프로필 | `https://hinsrolin.neocities.org/w?src=인스타프로필` |
| 인스타 스토리 | `https://hinsrolin.neocities.org/w?src=인스타스토리` |
| 카톡 단톡방 | `https://hinsrolin.neocities.org/w?src=카톡단톡방` |
| 그냥 짧게 | `https://hinsrolin.neocities.org/w` |

🔒 관리자 → 📊 방문 경로 → **🔗 추적 링크 만들기**도 이제 짧은 주소로 만들어 줍니다.

### 3. HTML 올리기 (새 그림 없음)

**[웰컴투 원기랜드.html](https://github.com/changdkand3-pixel/-/raw/claude/adoring-darwin-mewhr1/wonkiland-v82/%EC%9B%B0%EC%BB%B4%ED%88%AC%20%EC%9B%90%EA%B8%B0%EB%9E%9C%EB%93%9C.html)** → **`드래곤볼 수학게임` 폴더**에 `웰컴투 원기랜드.html` 이름 그대로 덮어 올립니다.

그림까지 한 번에 받기: [wonkiland_v82_neocities.zip](https://github.com/changdkand3-pixel/-/raw/claude/adoring-darwin-mewhr1/wonkiland-v82/wonkiland_v82_neocities.zip) (w.html 포함). **이번에 새로 생긴 그림 파일:** 없음 · **서버 코드:** 바꿀 것 없음

## 바뀐 점 (81차 → 82차)

1. **짧은 주소 `/w`**: 누르면 광고·미리보기 없이 바로 원기랜드가 열립니다. 카톡·인스타에 올리면 원기랜드 미리보기 카드(제목·대표 그림)도 그대로 나옵니다.
2. 짧은 주소로 들어와도 **들어온 곳(인스타·카톡·네이버 블로그 등)과 추적 이름(`src`)이 그대로 기록**됩니다.
3. 추적 링크 만들기가 짧은 주소로 만들어 줍니다(긴 주소도 함께 보여 줌).
4. 82차 업데이트 안내 카드 (주인장 기기에서만 보임).
