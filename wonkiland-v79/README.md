# 원기랜드 79차 — 설치 안 한 "회전찻잔"이 보이던 문제

## 원인

서버에 저장된 **주인장 공원**에 `회전찻잔` 건물 1개가 들어 있었습니다. 11월 12일 오전 1시 10분(한국 시간)에 **📤 주인장 공원 올리기**로 올라갔습니다.
- 이 기능은 관리자 Google 로그인이 있어야 올라가므로, 주인장 기기에서 올라간 것입니다.
- 그 기기에 예전에 놓아 둔 건물(51차부터 건물 그림을 누르면 바로 놓임)이 함께 올라간 것으로 보입니다.
- 방문자 지도는 이 주인장 공원을 보여 주기 때문에 회전찻잔이 보였습니다.
- 그리고 지금까지는 건물을 다 지우면 "지은 건물이 없어요"라며 **주인장 공원을 비울 수 없었습니다.**

## 회전찻잔 없애는 방법 (79차 올린 뒤)

1. 주인장 기기(일반회원 로그인 안 한 상태)에서 원기랜드를 엽니다.
2. 지도의 **회전찻잔을 눌러 빨간 ✕로 지웁니다.**
3. **🔒 관리자** → 비밀번호 → **🏰 주인장 공원 올리기·비우기**를 누릅니다.
   - 다른 건물이 남아 있으면 올라갈 건물 이름이 나옵니다. 확인하고 올립니다.
   - 건물이 하나도 없으면 "주인장 공원을 비울까요?"가 나옵니다. 확인하면 방문자 지도에서 사라집니다.
4. 관리자 메뉴의 **"🏰 지금 방문자에게 보이는 주인장 공원"** 칸에서 결과를 확인합니다.

## 바뀐 점 (78차 → 79차)

1. 주인장 공원을 올리기 전에 **올라갈 건물 이름 목록**을 보여 주고 확인합니다.
2. 이 기기에 건물이 없으면 **주인장 공원 비우기**로 올립니다.
3. 관리자 메뉴에 **지금 방문자에게 보이는 주인장 공원**(건물 이름·올린 시각)과 이 기기에 지은 건물 수를 보여 줍니다.
4. 79차 업데이트 안내 카드 (주인장 기기에서만 보임).
