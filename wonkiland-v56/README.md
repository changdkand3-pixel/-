## Neocities에 올리는 방법

1. zip을 받아 압축을 풉니다.
2. Neocities 대시보드에서 원기랜드 HTML을 올리던 폴더(예: `드래곤볼 수학게임`)를 엽니다.
3. `wonkiland_v56.html` 파일과 `images`, `music` **폴더를 그 폴더에 끌어다 놓습니다.** 세 가지가 반드시 **같은 폴더**에 있어야 그림과 음악이 나옵니다.
   - 폴더째 끌어다 놓기가 안 되면: Neocities에서 **New Folder**로 `images`와 `music` 폴더를 만들고, 각 폴더를 열어 안의 파일들을 끌어다 놓으세요.
4. `wonkiland_v56` 주소로 열어 확인합니다. 예전처럼 `웰컴투 원기랜드.html` 이름을 쓰고 싶으면 HTML 파일 이름만 바꿔서 올리면 됩니다. (폴더 이름은 바꾸면 안 됩니다.)

**다음 업데이트부터는** HTML 파일과 새로 생긴 그림·음악만 올리면 됩니다. 그림·음악 파일 이름은 내용으로 정해져서, 이미 올린 파일은 다음 차수에서도 이름이 같습니다. 새로 생긴 파일 목록은 각 차수 안내문에 적어 드립니다.

## 바뀐 점 (55차 → 56차)

- 기능은 55차와 똑같습니다.
- HTML 안에 넣어 두었던 그림·음악을 `images`, `music` 폴더의 파일로 꺼냈습니다. HTML이 30.4MB → 6.0MB로 줄었고, 가장 큰 파일도 0.9MB라 Neocities의 한 파일 80MB 제한과 상관이 없습니다. 화면을 열 때 필요한 그림만 받아서 처음 열리는 속도도 빨라집니다.
- 수학 초1-1·1-2 문제 그림(3.5MB)은 코드 안에 다른 형식으로 들어 있어 HTML에 그대로 두었습니다.
- 56차 업데이트 안내 카드.
