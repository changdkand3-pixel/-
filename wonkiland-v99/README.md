## 바뀐 점 (98차 → 99차)

1. **랜덤 뽑기**: 예전에는 취미코스가 약 90% 나와서 종교코스는 거의(약 2%) 안 나왔습니다. 이제 6개 코스(직업·종교·모임·취미·기타·추억)가 **똑같은 확률**로 나옵니다. (시험: 300번 뽑기 → 종교 50·직업 59·모임 48·취미 43·기타 47·추억 53)
2. 종교코스가 뽑히면 ①~⑥ 중 하나와 그 **세부 항목까지** 뽑아서 창을 열어 줍니다(예: `2. 종교코스 └ 가톨릭 청년 성서모임 └ 오늘의 말씀`).
3. **고침**: 96차 종교 ⑥ 기타 메뉴가 원래 있던 **5. 기타코스**와 이름이 겹쳐서, 5. 기타코스를 누르면 종교 기타 메뉴가 열리거나 칸 위치가 어긋날 수 있었습니다. 이름을 따로 나눠서 각각 제대로 열립니다.
4. 99차 업데이트 안내 카드.
