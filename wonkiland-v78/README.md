## 바뀐 점 (77차 → 78차)

1. **77·78차 업데이트 안내는 주인장 기기에서만** 뜹니다. 방문자·일반회원에게는 76차(풍경·날씨) 안내가 최신으로 보이고, 지난 업데이트 목록에도 77·78차가 나오지 않습니다.
2. **"다시 온 사람" 숫자 바로잡기:** 77차 전 기록에는 방문자 표시가 없어서 처음 왔는지 다시 왔는지 알 수 없는데, 모두 "다시 온 사람"으로 셌습니다. 이제 **"알 수 없음 (77차 전 기록)"** 으로 따로 셉니다. (서버 업데이트 후)
3. 78차 업데이트 안내 카드 (주인장 기기에서만 보임).
