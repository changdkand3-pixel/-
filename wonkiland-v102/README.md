## 바뀐 점 (101차 → 102차)

1. **테두리 어긋남:** 101차에서 그림 아래에 랜덤 줄을 붙이면서, 누르는 칸 위치가 "그림+랜덤 줄" 전체 높이 기준으로 계산되어 아래로 늘어나 보였습니다. 이제 그림과 칸을 그림 크기만 한 상자에 따로 넣어서 칸이 그림에 딱 맞습니다(종교코스 창·세부 창 6개 모두).
2. **랜덤 버튼이 가끔 안 눌림:** 늘어난 칸(특히 기타 메뉴 아래 줄)이 랜덤 버튼 위를 덮고 있어서, 누르면 랜덤 대신 그 칸이 눌렸습니다. 이제 칸이 그림 안에만 있어서 랜덤 버튼이 항상 눌립니다(PC·휴대폰에서 창마다 20번씩 시험, 모두 성공).
3. 102차 업데이트 안내 카드.
