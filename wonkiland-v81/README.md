## 비밀번호 바꾸는 방법

1. **🔒 관리자** → 지금 비밀번호로 엽니다.
2. **🔒 이 기기 비밀번호 변경** → 지금 비밀번호, 새 비밀번호(예: 숫자 4자리), 새 비밀번호 확인을 적습니다.
3. 비밀번호는 **기기(브라우저)마다 따로** 저장됩니다. 컴퓨터와 휴대폰에서 각각 바꿔 주세요.
