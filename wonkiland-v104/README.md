# 원기랜드 104차 — 관리자 비밀번호·Client ID 어디서나 같게

## 왜 그랬나요?

관리자 비밀번호와 Google Client ID는 지금까지 **그 브라우저 안에만** 저장되었습니다. 같은 휴대폰이라도 크롬·삼성 인터넷, 그리고 **카톡·인스타에서 링크를 눌러 열리는 안쪽 브라우저**는 저장 공간이 서로 따로입니다. 그래서
- 예전에 다른 브라우저에서 정한 **옛 비밀번호**가 나오기도 하고,
- 한 번도 안 연 브라우저에서는 **Client ID를 처음부터 다시** 물었습니다.

## 바뀐 점 (103차 → 104차)

1. **관리자 비밀번호를 서버에 저장**합니다(서버에는 비밀번호가 아니라 암호화한 값만). 어느 브라우저·기기에서 열어도 같은 비밀번호로 열립니다. 5번 틀리면 5분 잠금.
2. **Google Client ID는 서버에서 자동으로** 받아 옵니다. 다시 입력할 필요가 없습니다.
3. "🔒 이 기기 비밀번호 변경" → **"🔒 관리자 비밀번호 변경"**: 바꾸면 Google 관리자 로그인 뒤 서버에 저장되어 모든 기기에 적용됩니다.
4. 상상코칭 회원관리 비밀번호 칸과 방명록 삭제 비밀번호도 이 관리자 비밀번호로 열립니다(예전 비밀번호도 그 브라우저에서는 그대로 됨).
5. 서버가 아직 예전 코드면 지금처럼 그 브라우저의 값을 씁니다.
6. 104차 안내 카드는 주인장 기기에서만 보입니다.

## 해야 할 일 (순서대로)

1. **서버 코드 바꾸기:** [Code.gs(서버에 붙여넣기).txt](https://github.com/changdkand3-pixel/-/raw/claude/adoring-darwin-mewhr1/wonkiland-v104/Code.gs(%EC%84%9C%EB%B2%84%EC%97%90%20%EB%B6%99%EC%97%AC%EB%84%A3%EA%B8%B0).txt)를 "제목 없는 프로젝트"의 **Code.gs에 전부 붙여넣고**, **배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누릅니다(같은 주소 유지).
2. **HTML 올리기:** [웰컴투 원기랜드.html](https://github.com/changdkand3-pixel/-/raw/claude/adoring-darwin-mewhr1/wonkiland-v104/%EC%9B%B0%EC%BB%B4%ED%88%AC%20%EC%9B%90%EA%B8%B0%EB%9E%9C%EB%93%9C.html) → `드래곤볼 수학게임` 폴더에 덮어 올리기(새 그림 없음).
3. **비밀번호 한 번 정하기:** 주로 쓰시는 기기에서 🔒 관리자 → 지금 비밀번호로 열기 → **🔒 관리자 비밀번호 변경** → 새 비밀번호 → Google 관리자 로그인. 이제부터 모든 기기·브라우저에서 이 비밀번호입니다.
