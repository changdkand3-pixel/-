## 1. 휴회 이동이 동기화 뒤 되돌아가던 문제

**원인:** 휴회 이동·재원 복귀를 누르면 이 기기에서는 옮겨졌지만 **"언제 바뀌었는지(수정 시각)"를 새로 적지 않았습니다.** 동기화는 수정 시각이 더 최신인 쪽을 따르기 때문에, 서버의 "현재회원" 상태가 덮어써서 되돌아갔습니다.

**바뀐 점:** 휴회 이동·재원 복귀 때 수정 시각을 새로 적습니다. 동기화하면 서버와 다른 기기에도 휴회 상태가 그대로 반영됩니다. 누르면 아래에 "💤 ○○ 휴회 이동 · 다음 동기화 때 클라우드에도 반영돼요"가 보입니다.

→ 84차를 올린 뒤 **휴회 이동 → ☁ 전체 동기화**를 한 번 해 주세요.

## 2. 직업코스를 누르면 코스 바로가기 바가 가운데 뜨던 문제

**원인:** "코스 바로가기 · 전체 목록" 바가 코스 창(직업코스 등)보다 위 층에 그려져서, 코스 창 위에 겹쳐 보였습니다.

**바뀐 점:** 코스 창이 열려 있는 동안에는 바로가기 바가 창 뒤로 갑니다. 모든 코스 창에 적용됩니다.

## 3. 업데이트 안내

- 84차 안내 카드는 방문자에게도 보입니다(쉬운 말: "코스 창이 깔끔하게 보여요").
- 방문자에게는 주인장 전용 차수(77~83차)가 지난 업데이트 목록과 이전/다음 버튼에서 아예 나오지 않게 했습니다(76차 → 84차로 바로 이어짐).
