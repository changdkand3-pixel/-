## 원인

72차부터 구경하기 화면을 먼저 열었는데, **관리자 Google 로그인 창이 그 화면보다 아래에 그려져서 가려졌습니다.** 로그인을 할 수 없으니 "회원 명단을 불러오는 중…"에서 계속 멈춰 있었습니다. (관리자 메뉴에서 "7일·30일 통계 보기"나 "방문 기록 보기"를 눌렀을 때도 같은 문제가 있을 수 있었습니다.)

## 바뀐 점 (72차 → 73차)

1. **관리자 Google 로그인 창이 항상 맨 위에** 보입니다.
2. 로그인이 필요하면 구경하기 화면에 "🔐 관리자 Google 로그인 창에서 계정을 선택해 주세요"가 나옵니다.
3. **업데이트 안내: 관리자 내용은 주인장 기기에서만**
   - 방문자·일반회원에게는 관리자 기능(회원 공원 구경하기, 목록 불러오기, 방문 기록 보기, 서버 상태 등) 내용이 안 보이고, 쉬운 말로 바꾼 내용이 보입니다. 예: "화면과 연결 안정화".
   - 주인장 기기에서는 지금처럼 전체 내용이 보이고, 날짜 옆에 "🔒 관리자 내용 포함"이 붙습니다.
   - 64~73차에 적용했습니다. 70차 안내에는 "로그인한 회원의 방문(닉네임·시각)이 주인장에게 보여요"가 회원에게도 보입니다.
4. 73차 업데이트 안내 카드.
