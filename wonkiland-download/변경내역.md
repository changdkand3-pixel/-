# 원기랜드 v3 변경 내역

## 메뉴 배치
음악 메뉴와 비공개 테스트 버튼을 게임 화면의 게임 저장 버튼 바로 다음으로 옮겼습니다. 순서는 게임 저장 → 음악 메뉴 → 비공개 테스트 → 게임 불러오기입니다. 좁은 화면에서는 줄바꿈하며 버튼을 복제하지 않습니다. 기존 메인 화면 하단 메뉴 배치는 원본으로 복원했습니다.
기존 음악 위치 CSS가 버튼을 오른쪽 위에 놓지 못하도록 적용 우선순위를 정리했습니다.

## 비공개 테스트
비공개 테스트 버튼에서 비밀번호 5283을 입력하면 테스트 세션이 시작됩니다. 자료가 내장된 초1-1과 초1-2를 선택할 수 있습니다.
- 초1-1: 5개 단원, 13개 캐릭터
- 초1-2: 6개 단원, 23개 캐릭터
- 모든 단원과 자료가 있는 지도 지역에 승리 조건 없이 진입할 수 있습니다.
- 모든 캐릭터를 선택하고 친구 목록에서 볼 수 있습니다. 이미 친구인 상대도 테스트에서 다시 대결할 수 있습니다.
- 선두·방어막·파워 구슬·힌트 수정구를 각 99개 제공해 기능을 시험할 수 있습니다.
- 드래곤볼 표시와 소원 기록도 테스트용 상태로 확인할 수 있습니다.
기존에 자료가 없는 학년이나 콘텐츠는 새로 만들지 않았습니다.

## 일반 게임 보존
테스트 시작 전에 일반 게임 상태를 메모리에 보관하고 별도 테스트 상태로 전환합니다. 테스트 중 진행 기록은 localStorage에 저장하지 않으며 일반 게임 슬롯 저장·불러오기를 차단합니다. 테스트 종료 또는 게임 닫기를 누르면 일반 상태와 잠금을 복원합니다. 테스트 종료 후 다시 게임을 열면 일반 모드입니다.
일반 게임의 전투·점수·잠금 규칙은 유지했습니다. 회원관리·Google Apps Script·방명록·가구 배치, 이미지·오디오·문제 데이터는 v2와 텍스트 비교해 변경하지 않았음을 확인했습니다. 최초 원본과 v2도 작업 환경에 보관했습니다.

## 검증
Chromium 데스크톱 1280×900 및 모바일 390×844에서 다음 항목을 실제 클릭/터치로 검사했습니다.
- 저장 버튼 옆의 실제 메뉴 순서와 좌표, 정적 배치 확인
- 음악 재생/일시정지 및 슬라이더·+/− 음량 조절
- 비밀번호 오입력 시 진입 차단, 5283 입력 후 테스트 진입
- 두 학년의 모든 단원 진입 및 모든 지도 지역 잠금 해제
- 캐릭터 선택 및 친구 목록 전체 표시, 아이템 보유·사용·전투 진행
- 테스트 중 일반 저장 문자열 불변 및 슬롯 저장 차단
- 테스트 종료 후 일반 잠금과 기존 저장 문자열 복원
- 재인증·닫기 반복 후 관련 버튼·폼 이벤트 각 1회 연결
- 최초 로드 외 새로고침/페이지 이동 없음
- 32개 스크립트 구문 검사 통과, 새 실행 오류 없음

원본 회원 수강과목 코드의 cloneNode 오류는 여전히 있으며 변경 금지 요청에 따라 보존했습니다. Neocities 실제 배포 페이지는 환경 정책으로 403 응답을 받아 직접 검증하지 못했습니다. 검증은 로컬 HTTP 페이지에서 수행했으며 외부 동기화 서버에 쓰기는 하지 않았습니다.

## 적용
세 분할 파일을 합쳐 ZIP을 압축 해제하고 wonkiland_fixed_v3.html을 Neocities에 업로드한 뒤 새 v3 주소로 접속하세요. 비공개 테스트 메뉴는 게임 화면 안의 게임 저장 옆에 있습니다.
