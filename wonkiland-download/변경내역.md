# 원기랜드 v4: 초1-1 4단원 8명 구성

## 변경
초1-1 4단원 비교하기의 캐릭터 명단을 아래 8명으로 변경했습니다.

1. 푸알 (전투력 2)
2. 어린 손오공 (42)
3. 토끼 부르마 (4)
4. 우마왕 (65)
5. 치치 (37)
6. 오룡 (3)
7. 야무치 (34)
8. 무천도사 (75)

우마왕과 치치는 사용자가 ZIP으로 제공한 PNG를 재가공 없이 HTML에 내장했습니다. 기존 원본에서 우마왕에 푸알 이미지, 치치에 무천도사 이미지가 연결되어 있던 부분을 바로잡았습니다. 나머지 6명의 이미지는 그대로입니다. 원본 파일 바이트와 내장 이미지의 SHA-256 일치를 검증했습니다.

## 보존
v3와 텍스트 비교해 최초 캐릭터 이미지 데이터의 oxking/chichi 두 항목 및 초1-1 4단원 캐릭터 명단 외에는 변경하지 않았습니다. 메뉴 배치, 비밀번호 5283, 비공개 테스트, 일반 저장 기록 보호, 전투/보상 규칙, 음악, 회원관리, 동기화, 방명록, 가구 배치 및 초1-2 내용은 v3 그대로입니다.
비공개 테스트에서는 8명 모두 표시됩니다. 일반 게임의 기존 규칙에 따른 현재 플레이어 및 이미 친구가 된 상대의 제외 처리는 유지했습니다.

## 검증
Chromium PC 1280×900 및 모바일 390×844에서 5283으로 테스트에 들어가 4단원에 8명의 이름·서로 다른 이미지가 표시되는지 확인했습니다. 모든 이미지의 로드가 완료됐고 우마왕/치치 이미지는 업로드한 PNG 바이트와 일치했습니다. 각 캐릭터를 클릭해 8명 모두 대결 화면으로 진입했으며 신규 실행 오류는 없었습니다. 전체 32개 스크립트 구문 검사도 통과했습니다.
원본 회원 수강과목 cloneNode 오류는 기존과 동일하며 변경하지 않았습니다. 원격 동기화 서버에 쓰기 요청은 하지 않았고 실제 Neocities 배포 동작 검증은 환경에서 접근이 제한되어 수행하지 못했습니다.

## 사용
분할 파일 3개를 합쳐 ZIP을 풀고 wonkiland_fixed_v4.html을 Neocities에 올린 뒤 새 v4 주소를 여세요. 초1-1 → 4단원 비교하기에서 확인하세요.
