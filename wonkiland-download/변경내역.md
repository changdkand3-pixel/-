# v8 업로드 방법 — 이미지 원본 유지·HTML 크기 축소

기존 v7은 HTML 한 개가 약 118MB였습니다. v8은 HTML 약 65.2MB + 이미지 폴더 약 37.5MB(52개)로 나눴습니다. 이미지 원본 바이트와 음악은 그대로이며 재압축·축소하지 않았습니다. 음악은 기존처럼 HTML에 내장되어 별도 오디오 파일 업로드가 필요하지 않습니다.

## Neocities에 올리기

1. 기존 파일을 PC로 내려받아 백업하세요. 남은 저장 공간이 약 103MB보다 적다면 사용하지 않는 구버전 파일을 정리해 공간을 확보하세요. 다른 파일을 무작정 삭제하지 마세요.
2. 압축을 풀면 wonkiland_fixed_v8.html과 wonkiland_assets 폴더가 나옵니다.
3. Neocities의 기존 작업장 폴더 안에서 New Folder를 눌러 wonkiland_assets 폴더를 만드세요. 그 폴더 안으로 들어가 PC의 wonkiland_assets 안에 있는 이미지 52개를 모두 Upload하세요.
4. Neocities에서 작업장 폴더로 돌아와 wonkiland_fixed_v8.html을 Upload하세요.
5. 새 wonkiland_fixed_v8 주소를 여세요. HTML과 wonkiland_assets 폴더는 같은 위치에 있어야 합니다. HTML만 올리면 이미지가 표시되지 않습니다.

Neocities의 남은 저장 공간은 이 작업 환경에서 확인하거나 늘릴 수 없습니다. 기존 파일을 서버에서 삭제하지 않았습니다. 업로드 오류가 계속되면 대시보드의 사용량/남은 공간을 확인해야 합니다.

## 검증

분리한 이미지 경로를 원본 데이터로 다시 치환했을 때 v7 HTML과 정확히 일치함을 검증했습니다. 52개 파일의 SHA-256도 보존했습니다. 게임 규칙·전투력·모든 기존 기능은 그대로입니다.
Chromium PC·모바일에서 초1-2의 23개 이미지 원본 해시 일치, 6개 단원, 고유 상대 23종 대결 진입, 기존 저장 기록 유지 및 내장 음악 재생·일시정지·음량 조절을 확인했습니다. 32개 스크립트 구문 검사와 신규 실행 오류 없음도 확인했습니다. 원본 회원 수강과목 cloneNode 오류는 그대로입니다. 실제 Neocities 업로드와 계정 저장 공간은 검증하지 못했습니다.
