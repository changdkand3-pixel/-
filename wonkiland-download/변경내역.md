# 원기랜드 v7: 초1-2 원본 이미지 교체

업로드 ZIP의 원본 이미지 21장을 초1-2의 캐릭터·변형 23개 이미지 항목에 연결했습니다. 모든 이미지 바이트를 원본 그대로 사용했고 축소·재압축·새 이미지 생성은 하지 않았습니다. 같은 모습을 쓰는 손오공 괴물원숭이 420/860 및 푸알 2/3은 원본을 공유합니다. 잭기춘 일반/132/에네르기파와 오룡 3/4는 제공된 별도 그림으로 구분했습니다. 초1-2-이미지연결.md에서 파일별 연결을 확인할 수 있습니다.

v6와 비교해 초1-2의 PT 이미지 데이터만 바뀌었음을 확인했습니다. 초1-1, 캐릭터 이름·전투력·명단, 단원, 수학 문제와 정답, 전투·점수·보상 규칙, 게임 저장, 음악, 비공개 테스트, 회원관리·Google Apps Script 동기화·방명록·가구 배치는 그대로입니다.

Chromium PC 1280×900 및 모바일 390×844에서 다음을 검증했습니다.
- 초1-2 전체 23개 이미지 항목 로드 및 원본 SHA-256 일치 (원본 21장)
- 기존 캐릭터 이름과 전투력 표시 유지
- 6개 단원의 상대 목록 (5·8·9·11·8·8명)과 고유 상대 23종 전투 진입
- 일반 저장 기록 유지, 최초 로드 외 페이지 이동 없음
- 32개 스크립트 구문 검사 통과, 새 실행 오류 없음

원본 회원 수강과목 cloneNode 오류는 이전과 동일하게 남아 있습니다. 실제 Neocities 배포 검증 및 외부 서버 쓰기는 수행하지 않았습니다.

## 사용
분할 파일은 이번에 4개입니다. 모두 합쳐 ZIP을 푼 뒤 wonkiland_fixed_v7.html을 Neocities에 업로드하고 새 v7 주소로 접속하세요. 이미지가 HTML에 내장되어 별도 이미지 폴더 업로드는 필요하지 않습니다. 원본 이미지이므로 HTML 크기는 약 118MB입니다.
