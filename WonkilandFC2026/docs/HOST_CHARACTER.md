# 개최자 장원기 캐릭터 설계

## 원칙: "단일 정의 → 단일 모델"
- 외형 정의는 **`Data/host/host_character.json` 하나뿐**입니다.
- 프로토타입은 게임 시작 시 이 정의로 모델을 **한 번만** 만들고(`WFCModels.buildHost`), 모든 장면에서 같은 인스턴스를 위치·포즈만 바꿔 재사용합니다.
  → 장면마다 얼굴이 달라지지 않습니다.
- UE5에서도 같은 원칙: MetaHuman 블루프린트 1개(`BP_Host_JangWonki`)를 모든 시퀀서 장면에서 참조.

| 특징 | 반영 방식 (프로토타입) |
|---|---|
| 얼굴 | 사진 얼굴 영역 크롭 → 머리 앞면 텍스처 (`host_face_crop.png`) |

| 체격 | 넓은 어깨·두꺼운 몸통 (`build: 1.22`), 둥근 얼굴(머리 스케일 1.08~1.12) |

| 복장 | 사진은 니트 스웨터지만, 요청대로 **고급 정장**: 네이비 수트, 흰 셔츠, 버건디 넥타이, 포켓치프, 검정 구두 |

⚠️ 현재는 **사진 텍스처를 구형 머리에 붙인 수준**이며 실사 3D 얼굴이 아닙니다.

## UE5 실사 제작 절차 (다음 단계)
1. **추가 촬영**: 정면 1장만으로는 3D 얼굴 복원이 부정확합니다. 정면·좌우 45°·좌우 90°·위아래, 무표정/웃음 각각, 균일 조명, 고해상도(가능하면 휴대폰 사진측량용 30~60장).
2. **Mesh to MetaHuman**: 사진측량(RealityCapture 등) 메시 → MetaHuman Creator에서 정밀 조정 → 피부 텍스처/주름/머리카락(그룸) 설정.
3. 체형: MetaHuman 바디 프리셋 중 넓은 어깨·두꺼운 체형 선택, 키/체중은 본인 확인 수치 입력.
4. 의상: Marvelous Designer 또는 MetaHuman 의상 → 네이비 정장 세트.
5. 시퀀서: 위 장면 10개를 Level Sequence로 제작, 모두 같은 `BP_Host_JangWonki` 바인딩.
6. **권리**: 공개 배포 전 본인 서면 초상 사용 동의서 보관 (`docs/RIGHTS_REGISTER.md`).
