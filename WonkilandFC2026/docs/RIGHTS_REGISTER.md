## 반드시 확인이 필요한 영역 (향후)
| 분야 | 주의 사항 |
|---|---|
| **선수 실명·초상(퍼블리시티권)** | 생존 선수/유족·협회·선수협(FIFPRO 등) 라이선스 검토. 실명 사용 자체도 국가별로 법적 검토 필요 |
| 선수 얼굴 사진 | 사진 저작권은 촬영자/언론사 소유 — 퍼블릭 도메인 여부 개별 확인 |
| "월드컵/FIFA World Cup" 명칭·엠블럼·트로피 | FIFA 등록상표 — 게임 내에서는 "원기랜드 월드컵" 등 자체 명칭 사용 중. 공개 배포 전 상표 검토 |
| 국가대표 엠블럼·유니폼 디자인 | 각 협회 및 용품사 권리 — 현재 색상만 사용 |
| 경기장 이름·구조 | 일반적으로 사실 정보이나, 상업 배포 시 확인 권장 |
| 음악 | 사용자가 추가하는 파일은 아래 표에 기록 (상업적 이용·재배포 허용 여부 필수) |
| 해설 음성 | 성우 녹음 시 계약서 보관 |
