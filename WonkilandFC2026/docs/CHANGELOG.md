## v0.2.0 — 2026-11-25 · 역대 월드컵 선수 전원 + 드림팀
### 데이터
- 공개 데이터베이스 **Fjelstul World Cup Database (CC-BY-SA 4.0)** 원본 CSV를 `Data/sources/fjelstul/`에 보관
- `Tools/import_fjelstul.js` 신규: 남자 월드컵 22개 대회(1930–2022) → 스쿼드 489개, 선수 버전 10,973명(실제 인물 8,482명), 경기 964개, 득점, 수상, 최종 순위
- 능력치 자동 추정: 팀 성적, 출전 비중(1970~), 득점, 수상, 대회 경험, 경력 전체 기록 → 19개 능력치 (전원 `estimated: true`)
- 기존 수작업 1930 결승 데이터는 `Data/curated/`로 옮겨 원본 위에 덮어쓰는 보정값으로 유지 (한글 이름, 결승 선발 순서, 능력치)
- 표기 차이 발견: 우루과이 GK 'Ballesteros'(데이터베이스) / 'Ballestrero'(통용 표기) → 데이터에 기록, 확인 필요
- 국가 84개 메타데이터(`Data/nations`): 한글 이름, 표시 코드, 유니폼 색상 근사치
- 시대별 규칙 프로필 4종 추가 (1970, 1982, 1990, 1998)
- 팀 코드가 데이터베이스 표기로 변경: 우루과이 `URU` → `URY` 등 (화면에는 FIFA식 코드 표시)
- `Tools/build_data.js`: 압축 번들(2.1 MB) + 검증 강화 (출처 없는 신장·체중·주발 값 금지 등)

### 테스트 중 발견·수정한 버그
- 패스 속도 계산: 도착속도 0이 기본값 3으로 바뀌던 문제
- 롱패스 공기저항 보정 부족(30 m 목표가 25 m 착지) → 시뮬레이션 반복 보정
- 골키퍼가 PK를 슛을 보고 반응해 전부 막던 문제 → 차는 순간 방향 예측 방식
- 골키퍼 손 맞고 들어간 슛이 골키퍼 자책골로 기록되던 문제 → 슈터 득점으로
- 스로인이 자기 골키퍼에게 향하고 골키퍼가 팀 동료의 공에 다이빙해 자책골이 나던 문제(12경기 중 자책골 7개 → 0개)
- 저사양(낮은 FPS)에서 경기 시간이 느려지는 문제 → 고정 시간 간격 서브스텝
- 색이 바래 보이던 문제(색 관리), 개최자 얼굴 텍스처가 머리 옆에 붙던 문제, 시상식에서 개최자가 뒤돌아 있던 문제
