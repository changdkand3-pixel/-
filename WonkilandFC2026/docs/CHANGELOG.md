- 화면: 3D 타이틀, 오프닝, 개최 선언, 개막식, 선수 소개, VIP 관람, 시상식, 폐막식, 조 추첨식, HUD·미니맵, 일시정지(포메이션/전술/카메라/날씨/시간대), 결과 화면, 편집 모드

- 주간/해질녘/야간, 맑음/비/눈 (공 마찰 변화)
- 입력: 키보드 1인/2인, 게임패드·조이스틱
- 사운드: 합성 효과음·관중, 한국어 텍스트/음성 해설, 음악 재생 시스템(폴더 등록·즉석 추가·자동/랜덤)

### 테스트 중 발견·수정한 버그
- 패스 속도 계산: 도착속도 0이 기본값 3으로 바뀌던 문제
- 롱패스 공기저항 보정 부족(30 m 목표가 25 m 착지) → 시뮬레이션 반복 보정
- 골키퍼가 PK를 슛을 보고 반응해 전부 막던 문제 → 차는 순간 방향 예측 방식
- 골키퍼 손 맞고 들어간 슛이 골키퍼 자책골로 기록되던 문제 → 슈터 득점으로
- 스로인이 자기 골키퍼에게 향하고 골키퍼가 팀 동료의 공에 다이빙해 자책골이 나던 문제(12경기 중 자책골 7개 → 0개)
- 저사양(낮은 FPS)에서 경기 시간이 느려지는 문제 → 고정 시간 간격 서브스텝
- 색이 바래 보이던 문제(색 관리), 개최자 얼굴 텍스처가 머리 옆에 붙던 문제, 시상식에서 개최자가 뒤돌아 있던 문제
