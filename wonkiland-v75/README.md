## 원인

- 실제 서버로 게시판을 열면 약 2초에 열립니다.
- 그런데 68차의 "바로 주고받기"는 **한 번이라도 실패하면 그 화면에서는 계속 예전 숨은 창 방식으로 바뀌었습니다.**
- 구글 서버는 가끔 정상 답 대신 오류 페이지를 보내는데, 그것 한 번에도 바뀌었습니다. 숨은 창 방식은 브라우저에 따라 아주 느리거나 막혀서 게시판·동기화가 오래 걸렸습니다.

## 바뀐 점 (74차 → 75차)

1. 구글 오류 페이지나 일시적인 오류가 오면 **바로 주고받기로 다시 요청**합니다(최대 4번).
2. 연결이 막힌 경우에도 **그 요청만** 숨은 창 방식으로 보내고, 두 번 연속 막힐 때만 바꿉니다.
3. 게시판을 불러오는 동안 **기다린 시간**("· 12초째")을 보여 주고, 15초가 넘으면 **🔄 다시 불러오기** 버튼이 나옵니다.
4. 75차 업데이트 안내 카드.

이 개선은 방명록·전체 동기화·회원 공원 구경하기·방문 기록 등 모든 서버 요청에 적용됩니다.
