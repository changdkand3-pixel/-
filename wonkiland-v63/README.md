# 원기랜드 63차 — 일반회원 기록 클라우드 저장

## 해야 할 일 2가지

### 1. 서버 코드 바꾸기 (먼저!)

1. 받기: **[Code.gs(서버에 붙여넣기).txt](https://github.com/changdkand3-pixel/-/raw/claude/adoring-darwin-mewhr1/wonkiland-v63/Code.gs(%EC%84%9C%EB%B2%84%EC%97%90%20%EB%B6%99%EC%97%AC%EB%84%A3%EA%B8%B0).txt)**
2. [script.google.com](https://script.google.com)에서 회원 서버 프로젝트를 엽니다. 구글 드라이브의 **"제목 없는 프로젝트"**(10월 30일에 만든 것, 안에 `Code.gs`와 `CloudSync.gs`가 있음)입니다.
3. 왼쪽 파일 목록에서 **`Code.gs`**를 누르고, 안의 내용을 **모두 지운 뒤**(Ctrl+A → Delete) 받은 파일 내용을 **전부 붙여넣고 저장**(Ctrl+S)합니다.
4. 오른쪽 위 **배포 → 배포 관리 → 연필(수정) → 버전: "새 버전" → 배포**를 누릅니다. 주소(`/exec`)는 그대로 유지됩니다. **새 배포를 만들면 주소가 바뀌니 꼭 "배포 관리"에서 수정**하세요.

바뀐 내용: 일반회원 기록 저장·불러오기 기능 2개만 추가했습니다. 기존 회원·방명록·방문자 기능은 한 글자도 바꾸지 않았습니다. 기록은 같은 스프레드시트의 새 시트 **"일반회원진행기록"**에 저장됩니다(처음 저장할 때 자동으로 생김).

## 이렇게 동작합니다

| 누가 | 저장 위치 | 업데이트 후 | 다른 기기 |
|---|---|---|---|
| 로그인 안 한 방문자(공유받은 사람) | 자기 기기 브라우저 | 그대로 남음 | 안 보임 |
| **일반회원(로그인)** | **계정(클라우드) + 기기** | 그대로 남음 | **로그인하면 복원** |

- 일반회원이 로그인하면 계정에 저장된 **공원 건물·수학 기록·수학 저장 칸·영어 기록·영어 저장 칸**을 불러옵니다. 처음 로그인하는 회원은 지금 그 기기의 기록이 계정에 처음 저장됩니다.
- 로그인한 동안에는 **45초마다, 화면을 닫거나 다른 앱으로 갈 때, 저장 버튼을 누를 때** 자동으로 계정에 저장됩니다.
- 로그아웃하면 계정에 저장한 뒤, 그 기기의 **원래 손님 기록**으로 돌아갑니다. 그래서 같은 기기를 여러 회원이 써도 서로 섞이지 않습니다.
- 서버 코드를 아직 안 바꿨다면 로그인할 때 "서버가 아직 진행 기록 저장을 지원하지 않아요" 알림만 나오고, 기록은 지금처럼 기기에 저장됩니다.

## 확인한 것

가짜 서버로 시험: 첫 로그인 → 계정에 저장 / 다른 기기에서 같은 회원 로그인 → 수학·건물 기록 복원 / 로그아웃 → 그 기기 손님 기록으로 복구 / 다른 회원 로그인 → 기록이 섞이지 않음 / 서버 미지원 → 안내만 하고 기록 유지. 실제 Neocities 그림 불러오기, 수학 초3-2, 건물, 업데이트 기록, 동기화 결과, 스크립트 65개 구문 오류 없음. 실제 회원 서버에서의 저장은 서버 코드를 바꾼 뒤 확인이 필요합니다.
